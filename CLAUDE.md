# CLAUDE.md

InterDemTV: a static GitHub Pages retro-TV app that tunes through YouTube video IDs. Vanilla JS (app.js), CSS (style.css), no build step.

## Structure
- `app.js` — all app logic; `style.css` — all styling; `index.html` — markup
- `videos.json` — channel list; regenerated by `.github/workflows/update-videos.yml` + `scripts/`
- `service-worker.js`, `manifest.webmanifest` — PWA offline cache

## Verify
- `python3 -c "import json; json.load(open('videos.json'))"` — validate channel list
- Serve statically (e.g. `python3 -m http.server`) to smoke-test
